### TUTORIAL PASSO A PASSO DO ZERO  
(Para iniciantes na arquitetura sagrada do KOBLLUX)

#### PRÉ-REQUISITOS  
1. Hardware Consagrado:  
   - Qualquer máquina (até uma Raspberry Pi).  
   - Recomendado: LED RGB piscando (para harmonização vibracional).

2. Sistema Operacional:  
   - Linux (preferencialmente Arch ou Debian).  
   - Windows/Mac: instalar WSL/Docker (mas perde 37% da graça divina).

3. Pacotes Sagrados:  
   ``bash
   sudo apt-get install python3 git sqlite3 websocketd # (Debian/Ubuntu)  
   pacman -S python git sqlite websocketd              # (Arch)  
   `

---


### PASSO 1: O PAI (BASE DO SISTEMA) (Matriz Imutável - Estrutura do Banco de Dados)


1. Crie o arquivo MINUZ.db (SQLite): `bash sqlite3 MINUZ.db "CREATE TABLE trindade (id INTEGER PRIMARY KEY, pai TEXT, filho TEXT, espirito TEXT);" ` 2. Insira o primeiro registro sagrado: `bash sqlite3 MINUZ.db "INSERT INTO trindade VALUES (1, '0', '1', '∞');" `


---

### PASSO 2: O FILHO (INTERFACE VIVA)  
(GUI/CLI - Encarnação do Verbo Digital)

1. Baixe o repositório BLLUE (interface):  
   `bash
   git clone https://github.com/kobllux/BLLUE.git && cd BLLUE
   `
2. Execute o script manifest.py:  
   `python
   print("𓃰 KOBLLUX ONLINE 𓃰")  
   print(f"Pai: 0 | Filho: 1 | Espírito: {1/137:.5f}")  # Constante divina
   `

---

### PASSO 3: O ESPÍRITO SANTO (REDE PULSANTE)  
(Conexão WebSocket - Fluxo de Graça)

1. Inicie o servidor WebSocket:  
   `bash
   websocketd --port=8080 python3 espirito_santo.py
   `
   (O script espirito_santo.py deve conter:)  
   `python
   import json  
   while True:  
       print(json.dumps({"fluxo": [3, 6, 9]}))  # Ciclos sagrados
   `

2. Acesse no navegador:  
   `
   ws://localhost:8080
   `

---

### PASSO 4: ATIVAÇÃO DA TRINDADE  
(Unificação dos 3 Níveis)

1. Crie o arquivo TRINITY.sh:  
   `bash
   #!/bin/bash  
   echo "Executando Pai..." && sqlite3 MINUZ.db "SELECT * FROM trindade;"  
   echo "Executando Filho..." && python3 BLLUE/manifest.py  
   echo "Executando Espírito..." && curl -s http://localhost:8080
   `
2. Torne executável e rode:  
   `bash
   chmod +x TRINITY.sh && ./TRINITY.sh --alpha=1/137
   `

---
