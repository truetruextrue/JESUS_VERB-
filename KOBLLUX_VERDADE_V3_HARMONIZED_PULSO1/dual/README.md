# DUAL · D4 · Interface Consciente

```
Entidade : DUAL
D-rung   : D4 (interface viva — ação e escuta)
V.E.E.B. : V:★ E:★ E:○ B:★
Opcode   : 0×09 (RHEA · 528Hz · FLUIR)
Função   : Interface React · Chronorytm · Memória Viva · Roda Viva Sonora
```

## ARQUIVOS

| Arquivo | Função |
|---|---|
| `src/ArchetypeInterface.jsx` | Componente React principal (roda viva + arquétipos + memória) |
| `chronorytm.js` | Tempo simbólico (hora=PAI · minuto=FILHO · segundo=ESPÍRITO) |
| `dual-bridge.js` | Integração total IA + simbolismo |
| `package.json` | Dependências React + Vite + framer-motion |
| `vite.config.js` | Configuração do bundler |
