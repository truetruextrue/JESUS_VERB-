## 2. DIVERGÊNCIAS · GAPS A PREENCHER

### GAP-01 · Frequências Hz ausentes em a-infodose
**Problema:** a-infodose usa timings de animação (8s, 12s, 2s) mas não define Hz sagradas.  
**Python tem:**
```python
BLLUE   = 852  # Hz
JESUS   = 963  # Hz
KODUX   = 777  # Hz
SOLUS   = 528  # Hz
AION    = 639  # Hz
FUNDACAO = 432 # Hz
```
**Fix recomendado** (adicionar em kobllux_v3 ou splash.html):
```js
const KOB_HZ = {
  FUNDACAO: 432, SOLUS: 528, AION: 639, KODUX: 777,
  BLLUE: 852, JESUS: 963,
  FRACTAL: 3 * 6 * 9 * 7  // 1134
};
```

### GAP-02 · Trinity (PAI/FILHO/ESPIRITO_SANTO) ausente em a-infodose
**Problema:** a-infodose tem `trinity` como arquétipo/cor mas NÃO define a estrutura trinitária.  
**Python tem:**
```python
class TrinidadeLayer(Enum):
    PAI           = "PAI"
    FILHO         = "FILHO"          # JESUS — 963Hz
    ESPIRITO_SANTO = "ESPIRITO_SANTO"
```
**Fix recomendado** (meta ou comentário em HTML):
```html
<!-- TRINITY: PAI → FILHO(JESUS=963Hz=GRAVIDADE) → ESPIRITO_SANTO -->
```

### GAP-03 · "JESUS = VERBO = GRAVIDADE" ausente em a-infodose
**Problema:** Assinatura central do sistema não aparece no HTML.  
**Fix recomendado:** Adicionar ao splash ou footer do kobllux_v3:
```html
<span class="brand-center">JESUS = VERBO = GRAVIDADE</span>
```

### GAP-04 · digital_root() não visível em a-infodose
**Problema:** Python tem `_digital_root(n) = 1 + (n-1) % 9`. O módulo `0x07_selar_B_D3.js`
é externo, não foi possível confirmar se contém a função.  
**Fix recomendado** (verificar ou adicionar em selar module):
```js
function digitalRoot(n) { return n > 0 ? 1 + (n - 1) % 9 : 9; }
```

### GAP-05 · BankingInterdimensional ausente em a-infodose
**Problema:** Python tem `saldo_graca=963.0`, distribuição para KODUX/BLLUE/INFODOSE.  
Não há equivalente em HTML.  
**Fix recomendado:** Adicionar como estado visual (badge/counter):
```js
const BANKING = { saldo_graca: 963.0, ressonancia: 0.963 };
```

### GAP-06 · FRACTAL = 3×6×9×7 = 1134 ausente em a-infodose
**Presente em:** VERBO.py + codex-azure README  
**Ausente em:** a-infodose HTML  
**Fix:** incluir como constante no JS (ver GAP-01 fix acima)

### GAP-07 · Mapeamento ciclo Roda Viva → opcodes Python
