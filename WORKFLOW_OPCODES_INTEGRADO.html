📋 Fluxo de Execução

O workflow recebe um impulso PUK via webhook, estrutura os dados através do opcode 0x00, passa para inteligência integrada (IA Agent), que sintetiza uma resposta usando opcode 0x06, expande para WhatsApp/HTTP (0x09), e finalmente sela o registro em Google Sheets (0x07).
